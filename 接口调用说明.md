# 接口调用说明

## 📋 概述

项目使用 **Supabase** 作为后端服务，通过 Supabase 客户端库调用 API。所有接口调用都是通过 Supabase 客户端进行的，无需手动编写 HTTP 请求。

---

## 🔧 Supabase 客户端配置

### 1. 客户端初始化

**浏览器端客户端** (`utils/supabase/client.ts`)：

```typescript
import { createBrowserClient } from "@supabase/ssr";

export function createClient() {
  return createBrowserClient(
    process.env.NEXT_PUBLIC_SUPABASE_URL!,
    process.env.NEXT_PUBLIC_SUPABASE_ANON_KEY!
  );
}
```

**服务端客户端** (`utils/supabase/server.ts`)：

```typescript
import { createServerClient } from "@supabase/ssr";
import { cookies } from "next/headers";

export async function createClient() {
  const cookieStore = await cookies();
  
  return createServerClient(
    process.env.NEXT_PUBLIC_SUPABASE_URL!,
    process.env.NEXT_PUBLIC_SUPABASE_ANON_KEY!,
    {
      cookies: {
        getAll() {
          return cookieStore.getAll();
        },
        setAll(cookiesToSet) {
          // 处理 cookie 设置
        },
      },
    }
  );
}
```

## 📝 API 调用方式

### 1. 在客户端组件中调用

**步骤：**
1. 导入客户端创建函数
2. 创建 Supabase 客户端实例
3. 使用客户端调用 API

**示例：查询项目列表** (`app/projects/page.tsx`)：

```typescript
"use client";

import { createClient } from "@/utils/supabase/client";

export default function ProjectsPage() {
  const supabase = createClient();

  // 查询项目列表
  const fetchProjects = async () => {
    const { data, error } = await supabase
      .from("projects")           // 指定表名
      .select("*")                // 选择所有字段
      .order("created_at", { ascending: false }); // 排序

    if (error) throw error;
    setProjects(data || []);
  };
}
```

### 2. 在服务端组件中调用

**步骤：**
1. 导入服务端客户端创建函数
2. 使用 `await` 创建客户端（因为服务端是异步的）
3. 调用 API

**示例：服务端获取项目** (`app/page.tsx`)：

```typescript
import { createClient } from "@/utils/supabase/server";

export default async function Home() {
  const supabase = await createClient(); // 注意：需要 await
  
  // 获取当前用户
  const { data: { user } } = await supabase.auth.getUser();
  
  // 查询项目
  const { data: projects } = await supabase
    .from("projects")
    .select("*")
    .order("created_at", { ascending: false });
}
```

## 📊 数据库操作 API 调用

### 1. 查询数据 (SELECT)

**查询所有项目：**

```typescript
const { data, error } = await supabase
  .from("projects")
  .select("*")
  .order("created_at", { ascending: false });
```

**查询特定项目：**

```typescript
const { data, error } = await supabase
  .from("projects")
  .select("*")
  .eq("id", projectId)
  .single();  // 返回单条记录
```

**条件查询：**

```typescript
const { data, error } = await supabase
  .from("projects")
  .select("*")
  .eq("status", "active")      // 等于
  .neq("status", "completed")  // 不等于
  .gt("created_at", "2024-01-01")  // 大于
  .limit(10);  // 限制数量
```

### 2. 插入数据 (INSERT)

**创建新项目：**

```typescript
const { data: { user } } = await supabase.auth.getUser();

const { error } = await supabase
  .from("projects")
  .insert([
    {
      name: "项目名称",
      description: "项目描述",
      status: "active",
      owner_id: user.id,  // 必须使用当前用户 ID
    },
  ]);

if (error) {
  throw error;
}
```

### 3. 更新数据 (UPDATE)

**更新项目信息：**

```typescript
const { error } = await supabase
  .from("projects")
  .update({ 
    name: "新项目名称",
    description: "新描述",
    status: "completed",
  })
  .eq("id", projectId);  // 指定更新哪个项目

if (error) {
  throw error;
}
```

### 4. 删除数据 (DELETE)

**删除项目：**

```typescript
const { error } = await supabase
  .from("projects")
  .delete()
  .eq("id", projectId);

if (error) {
  throw error;
}
```

## 💡 实际代码示例

### 示例 1：项目管理页面 (`app/projects/page.tsx`)

```typescript
"use client";

import { createClient } from "@/utils/supabase/client";
import { useState, useEffect } from "react";

export default function ProjectsPage() {
  const supabase = createClient();
  const [projects, setProjects] = useState([]);
  const [loading, setLoading] = useState(true);

  // 1. 查询项目列表
  const fetchProjects = async () => {
    try {
      setLoading(true);
      const { data, error } = await supabase
        .from("projects")
        .select("*")
        .order("created_at", { ascending: false });

      if (error) throw error;
      setProjects(data || []);
    } catch (err) {
      console.error(err);
    } finally {
      setLoading(false);
    }
  };

  // 2. 删除项目
  const handleDelete = async (id: string) => {
    if (!confirm("确定要删除吗？")) return;

    try {
      const { error } = await supabase
        .from("projects")
        .delete()
        .eq("id", id);

      if (error) throw error;
      fetchProjects(); // 重新加载列表
    } catch (err) {
      alert("删除失败: " + err.message);
    }
  };

  useEffect(() => {
    fetchProjects();
  }, []);

  return (
    // ... UI 代码
  );
}
```

## 🔍 API 调用流程

```
前端组件/页面
    ↓
创建 Supabase 客户端
    ↓
调用 Supabase API 方法
    ↓
.supabase.from("table_name").select()  // 查询
.supabase.from("table_name").insert()  // 插入
.supabase.from("table_name").update()  // 更新
.supabase.from("table_name").delete()  // 删除
    ↓
Supabase 客户端库
    ↓
HTTP 请求（自动处理）
    ↓
Supabase API (localhost:54321)
    ↓
PostgreSQL 数据库 (localhost:54322)
    ↓
返回数据/错误
```

## 📚 常用 API 方法总结

### 认证 API

```typescript
// 注册
await supabase.auth.signUp({ email, password, options })

// 登录
await supabase.auth.signInWithPassword({ email, password })

// 登出
await supabase.auth.signOut()

// 获取当前用户
await supabase.auth.getUser()
```

### 数据库 API

```typescript
// 查询
await supabase.from("table").select("*")
await supabase.from("table").select("*").eq("column", value)
await supabase.from("table").select("*").order("created_at", { ascending: false })

// 插入
await supabase.from("table").insert([{ ... }])

// 更新
await supabase.from("table").update({ ... }).eq("id", id)

// 删除
await supabase.from("table").delete().eq("id", id)
```

## ⚠️ 注意事项

### 1. 客户端 vs 服务端

- **客户端组件** (`"use client"`)：使用 `createClient()` from `utils/supabase/client`
- **服务端组件**：使用 `await createClient()` from `utils/supabase/server`

### 2. 错误处理

```typescript
const { data, error } = await supabase.from("projects").select("*");

if (error) {
  // 处理错误
  console.error("错误:", error.message);
  throw error;
}

// 使用数据
console.log("数据:", data);
```

### 3. 用户认证

所有需要用户身份的操作，都需要先获取用户：

```typescript
const { data: { user } } = await supabase.auth.getUser();
if (!user) {
  // 用户未登录，重定向到登录页
  router.push("/login");
  return;
}
```

### 4. Row Level Security (RLS)

项目使用 RLS 策略，确保用户只能访问自己的数据。Supabase 会自动处理权限检查。

## 🎯 总结

1. **使用 Supabase 客户端**：无需手动编写 HTTP 请求
2. **链式调用**：`.from().select().eq().order()` 等
3. **自动处理**：认证、权限、错误处理都由 Supabase 处理
4. **类型安全**：TypeScript 支持，提供类型提示

**核心优势：**
- ✅ 无需手动编写 REST API
- ✅ 自动处理认证和权限
- ✅ 类型安全的数据库操作
- ✅ 实时数据同步（可选）
