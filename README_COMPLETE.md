## 🔧 配置说明

### AI 模型配置

#### 使用 Ollama（本地）
1. 安装 Ollama
2. 拉取模型：`ollama pull deepseek-coder:1.3b`
3. 在系统设置中配置：
   - API 地址：`http://localhost:11434`
   - 模型名称：`deepseek-coder:1.3b`
   - API Key：留空

#### 使用 OpenAI（云端）
1. 获取 OpenAI API Key
2. 在系统设置中配置：
   - API 地址：`https://api.openai.com/v1`
   - 模型名称：`gpt-3.5-turbo`
   - API Key：你的密钥

### 文件上传配置（可选）

要启用真实文件上传：
1. 在 Supabase Dashboard 创建 Storage Bucket
2. 配置 RLS 策略
3. 更新上传代码

## 🐛 故障排除

### 问题：迁移执行失败
**解决：**
- 检查 SQL 语法
- 按顺序执行
- 查看 Supabase 日志

### 问题：测试数据生成失败
**解决：**
- 确保已登录
- 检查网络请求
- 查看浏览器控制台

### 问题：向量化失败
**解决：**
- 检查 Ollama 是否运行
- 检查模型是否安装
- 检查 API 配置
- 查看错误详情

### 问题：通知数量不更新
**解决：**
- 刷新页面
- 检查数据库数据
- 查看网络请求
